## Purpose & Scope
Status: Accepted (2026-08-01).

This spec defines the lexical tag language: the identifier grammar, emission, token priority, maximal-prefix scanning, candidate enumeration, and the pinned Unicode and Emoji data. It is a Memos profile based on Unicode UAX #31 and Unicode Emoji data, not an unchanged UAX31-R8 or UAX #31 Emoji Profile. The Go lexer and the web lexer are normative subjects; payload extraction, the renderer, editor decoration, and completion depend on them for the same values and spans. Out of scope: Markdown-context eligibility and span use, tag identity and hierarchy, existing-data migration, rollout, backfill, and metadata remapping.

## Surface
- Go lexer: `FindTagMatches` in @markdown/parser/tag.go takes one eligible literal-source run and returns `TagMatch` values.
- Web lexer: `findTagMatches`, `scanTagAt`, and `isTagIntroducerAt` in @web/src/utils/tag-grammar.ts; `TagMatch` carries `from`, `to`, `source`, and `value`.
- Pinned data: @markdown/parser/tag_unicode_tables.go (generated by @markdown/parser/tagdata/main.go) and @web/src/utils/tag-unicode-data.ts.
- Terms: the *introducer* is the `#` that begins a candidate; the *source spelling* is every code point consumed after it, ignored ones included; the *direct tag value* is the emitted identifier.
- Normative grammar (no other copy exists in the repository):

```text
TagCandidate        := Introducer TagSourceSpelling
Introducer          := U+0023 NUMBER SIGN ("#") outside a FullyQualifiedEmoji
TagSourceSpelling   := TagSegmentSpelling ("/" TagSegmentSpelling)*
TagSegmentSpelling  := IgnoredPrefix* SegmentStarter SegmentContinuation*
IgnoredPrefix       := IgnoredDefaultIgnorable | IgnoredLeadingCombiningMark
SegmentContinuation := ValueUnit | ApostropheJoiner | IgnoredDefaultIgnorable
SegmentStarter      := EmittedXIDContinueCodePointExceptCombiningMark
                     | FullyQualifiedEmoji | "-" | "+" | "&"
ValueUnit           := EmittedXIDContinueCodePoint
                     | FullyQualifiedEmoji | "-" | "+" | "&"
ApostropheJoiner    := U+0027 APOSTROPHE ("'") | U+2019 RIGHT SINGLE QUOTATION MARK ("’")
IgnoredDefaultIgnorable     := Default_Ignorable_Code_Point outside a FullyQualifiedEmoji
IgnoredLeadingCombiningMark := XID_Continue with General_Category Mn or Mc,
                               minus Default_Ignorable_Code_Point, before SegmentStarter
```

## Normative Behavior
Emission
1. WHEN the lexer consumes a `SegmentStarter`, `ValueUnit`, or valid `ApostropheJoiner`, it MUST emit that token's exact source code-point sequence.
2. WHEN the lexer consumes a `FullyQualifiedEmoji`, it MUST emit the complete matched sequence as one atomic unit.
3. WHEN the lexer consumes a `/` separator, it MUST emit one U+002F SOLIDUS into the identifier.
4. The lexer MUST NOT emit the `Introducer`, an `IgnoredDefaultIgnorable`, or an `IgnoredLeadingCombiningMark`.
5. The lexer MUST return the emitted identifier as the direct tag value.
6. At every source position, the lexer MUST try the longest `FullyQualifiedEmoji`, then `IgnoredDefaultIgnorable`, then `IgnoredLeadingCombiningMark`, then a valid `ApostropheJoiner`, then other units.

Maximal-prefix scanning
7. WHEN the lexer finds an introducer, it MUST consume the longest valid `TagSourceSpelling` within the current literal-source run.
8. WHILE a segment has no starter yet, the lexer MUST consume default-ignorable and non-default-ignorable `Mn`/`Mc` `XID_Continue` code points without emitting them.
9. WHEN a segment starter has been emitted, the lexer MUST preserve later non-default-ignorable `XID_Continue` combining marks as value units.
10. WHEN a segment starter has been emitted, the lexer MUST keep consuming default-ignorable code points without emitting them.
11. WHEN U+0027 or U+2019 follows an emitted `EmittedXIDContinueCodePoint` in its segment and precedes an `EmittedXIDContinueCodePointExceptCombiningMark`, the lexer MUST emit it as a joiner.
12. The lexer MUST evaluate the joiner context of clause 11 after emoji-first tokenization.
13. The lexer MUST treat U+02BC MODIFIER LETTER APOSTROPHE as an ordinary `XID_Continue` code point, not as an `ApostropheJoiner`.
14. WHEN the source after a `/` and any ignored prefix can emit a segment starter, the lexer MUST consume the `/` and that segment.

Introducer and candidate enumeration
15. The scanner MUST treat only U+0023 outside a matched `FullyQualifiedEmoji` as an introducer.
16. The scanner MUST treat U+FE5F SMALL NUMBER SIGN and U+FF03 FULLWIDTH NUMBER SIGN as ordinary text.
17. The scanner MUST NOT require any character boundary before the introducer.
18. At each position, the scanner MUST match the longest `FullyQualifiedEmoji` before interpreting any constituent code point separately.
19. WHILE no candidate is active, the scanner MUST advance past a matched `FullyQualifiedEmoji` as one unit.
20. WHEN no emoji matches and the current code point is an introducer, the scanner MUST scan a tag candidate.
21. WHEN a candidate succeeds, the scanner MUST continue at the first unconsumed source position.
22. WHEN an ordinary `#` does not begin a `FullyQualifiedEmoji`, the lexer MUST terminate the current identifier before it.
23. WHEN a candidate stops before an ordinary terminating `#`, the scanner MUST reconsider that `#` as a possible next introducer.
24. WHEN the current code point is neither an emoji start nor an introducer, the scanner MUST advance by one code point.

## Constraints & Invariants
- `EmittedXIDContinueCodePoint` MUST be a Unicode 17.0 `XID_Continue` code point that is not a Unicode 17.0 `Default_Ignorable_Code_Point`.
- `EmittedXIDContinueCodePointExceptCombiningMark` MUST additionally exclude General Category `Mn` and `Mc`.
- `_` is already in `XID_Continue` and MUST NOT be modelled as a separate extension.
- `FullyQualifiedEmoji` MUST be a sequence whose `RGI_Emoji_Qualification` is `Fully_Qualified` (status `fully-qualified` in Emoji 17.0 `emoji-test.txt`).
- The `Standalone_Component` value (status `component`) MUST NOT match `FullyQualifiedEmoji`.
- The raw union of `Extended_Pictographic` and `Emoji_Component` MUST NOT define emoji units; it admits bare `*`, isolated components, invisible tag characters, and reserved code points.
- The `#` of `#️⃣` MUST stay inside that atomic emoji unit under the same longest-match rule as every other emoji.
- Numeric-only and emoji-only identifiers MUST be valid.
- `-`, `+`, and `&` MAY appear at any segment position, repeat, or form a whole segment.
- A segment MAY start without `XID_Start`: digits, `_`, `-`, `+`, `&`, and fully-qualified emoji are starters.
- A `/` MUST appear only between two non-empty segments; it never begins or ends an identifier, and two separators are never adjacent.
- Ignored code points MUST NOT make a segment non-empty by themselves.
- Default-ignorable code points inside a matched `FullyQualifiedEmoji` MUST be preserved as part of that unit.
- The lexer MUST NOT apply a tag-specific identifier length limit; the enclosing memo-size limit is the resource bound.
- Recognition MUST use the pinned Unicode 17.0 and Emoji 17.0 data, not Go, browser, or Node runtime tables.
- An update of either data set MUST go through an explicit specification change, because new `XID_Continue` characters and emoji sequences change what source means.

## Failure Behavior
1. IF the first `TagSegmentSpelling` cannot match, THEN the lexer MUST produce no candidate.
2. IF an introducer produces no candidate, THEN the scanner MUST advance by one code point, so an adjacent `#` is still considered.
3. IF the next code point cannot begin a valid continuation unit, THEN the lexer MUST stop before it.
4. IF a later code point is invalid, THEN the lexer MUST keep the valid prefix already consumed.
5. IF an apostrophe does not meet the joiner context of clause 11, THEN the lexer MUST stop before the apostrophe.
6. IF a `/` is followed, after any ignored prefix, by another `/`, a non-starter, or the run end, THEN the lexer MUST stop before it.

## Conformance
An implementation conforms when it satisfies clauses 1–24, every invariant, and every failure rule, and the Go and web lexers emit the same values and spans for one run. @web/tests/tag-unicode-parity.test.ts checks that both pinned tables carry one Unicode data digest; @markdown/parser/tag_test.go and @web/tests/tag-grammar.test.ts hold lexer cases.

Given the literal-source run `#foo,bar`.
When the lexer scans it.
Then it emits `foo` and leaves `,bar` unconsumed.
